# How to open an issue

1. Search the existing issues for the same behavior.
2. Open the repository's **Issues** tab and select **New issue**.
3. Choose **Bug report** for a defect. Give it a title that names the failed behavior, such as `Prices with thousands separators parse as NaN`.
4. Fill in the problem, reproduction, expected and actual results, evidence, and completion checklist. Include product IDs and artifact dates when they help reproduce a scrape or data problem.
5. Remove secrets, database connection strings, and personal information from logs before attaching them. Submit the issue.

Keep one issue focused on one behavior. If a code fix leaves existing data incorrect, include data repair in **Done when** so the issue stays open until the user-facing result is correct. Link related issues or pull requests in a comment.
